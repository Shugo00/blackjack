# ブラックジャック 0.1.0-rc2

WindowsとPCブラウザで遊ぶ，ブラックジャックの受入テスト候補．チップ・クイック・学習の3モードを備える．

## Windowsで始める

1. Windows用ZIPを保存し，右クリックの「すべて展開」で新しいフォルダへ展開する．
2. 展開先の `Blackjack.exe` をダブルクリックする．Python等の導入は不要．
3. `_internal` フォルダも必要なので，EXEだけを移動せずフォルダごと保管する．

対応対象はWindows 11 x64．ZIPの中から直接実行しない．未署名の個人制作アプリのため，Windowsが警告を表示する場合がある．受け取ったファイルの出所を確認した上で扱う．

## ブラウザで始める

配信URLをPCのEdgeまたはChromeで開く．初回はゲームと実行環境の読込みに時間がかかる．開始を促す表示が出たらページをクリックする．インターネット接続が必要で，オフライン起動は保証しない．

Web用ZIPは掲載用のファイルである．HTMLを直接ダブルクリックして遊ぶ形式ではない．iPhone・iPadは努力目標，Androidは対象外．

## 遊ぶ

- **チップ**：人間1〜4人とCPUで4席．ディーラーは別枠のCPU．4／6デッキを選べる．10・50・100のチップをクリックするか，自分のベット枠へドラッグして確定する．
- **クイック**：人間1〜4人で同じ端末を順番に操作．1デッキ，ヒット／スタンド，勝敗のみ．交代する人を確認して「操作を始める」を押す．
- **学習**：1人専用．基本／応用，チップ／クイック，助言あり／振り返りのみを選ぶ．応用の新しい卓ではRC／TCの入門ガイドが開く．途中でも「RC / TC の数え方」で読める．

各モードとも人間の判断と次局への移動は手動．チップはダブル・分割・保険・サレンダーを選べる局面で表示する．ディーラーはソフト17でヒットし，自然のブラックジャックは3:2．チップは初期1,000，通常ベット10〜100．人間の資金が精算後10未満になると卓を終了する．CPUの補充は損失を消さず，表示にマイナスを残す．

メニュー下部の大きな「対局に戻る」で再開．ホームを選ぶと確認が開き，右下の大きな「ホームへ戻る」で移動する．Enterはその画面の主ボタン，Escはメニュー／取消し．効果音は初期OFFで，メニューまたは設定からONにできる．BGMはない．

補助キー：H＝ヒット，S＝スタンド，D＝ダブル，P＝分割，R＝サレンダー．1／2／3＝チップ．Tabでボタン移動，Enterで決定．入力欄はクリックして入力する．

## 保存と受渡し

途中の卓は各モード1つずつ自動保存する．同じ起動方法でホームの「続きから」を選ぶ．名前別の累計と，最新100局の学習履歴を確認できる．

Windowsの保存先は `%LOCALAPPDATA%\ZatsuGames\Blackjack`．ブラウザは利用したブラウザと配信元の内部保存を使う．別PC・別ブラウザ・Windows版とブラウザ版では自動共有されない．引き継ぐ場合は「設定・保存管理」からJSONを書き出し，移行先で取り込む．取込みは移行先の全モード・全員の戦績・設定を置き換えるので確認画面を読む．

「未保存」が出た場合は保存データを書き出して保全し，再試行する．ブラウザのデータ消去やプライベート閲覧の終了で保存が失われることがある．

## 受入テストで確認すること

開発環境を持たない別PCへWindows ZIPまたはブラウザURLを渡し，起動，1局完走，途中で閉じて再開，名前入力，音ON／OFFを試す．問題があれば，版・OS・ブラウザ・行った操作・実際の表示を報告する．ゲームの完成判定は受入結果を確認してから行う．

この候補の別PCでの動作は，受け取った環境で確認する必要がある．コード上のテストを全機種の動作保証とは扱わない．
